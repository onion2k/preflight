Two failures worth checking twice

The first is robots.txt carrying a staging Disallow: / into production — invisible on the site itself, and it costs weeks of indexing. The second is a 404 page that returns HTTP 200, which quietly disables every broken-link tool you own and fills search results with a page saying nothing was found. Both take ten seconds with curl.
